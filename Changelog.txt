KoolCenter Lucky Changelog
===========================================
1.6.4
   - fix        恢复原 lucky 软件中心模块身份、Module_lucky.asp 页面、icon-lucky.png 图标及原有显示信息
   - change     仅将 softcenter_module_lucky_install 设置为 4，保持插件正常显示但不再与官方 Lucky 做版本更新比对
   - migrate    自动清理 1.6.3 临时 lucky_melin 身份残留，同时保留现有 lucky_ 设置和 /koolshare/configs/lucky 配置数据

1.6.3
   - change     软件中心模块身份从官方 lucky 分离为 lucky_melin，不再与路由器软件中心原 Lucky 插件做版本比较
   - change     插件标题改为 Lucky Merlin，作者改为 hwyc888，项目地址改为 hwyc888/lucky-melin
   - migrate    从 1.6.2 及更早版本升级时自动移除 softcenter_module_lucky_* 旧身份元数据，但保留 lucky_ 运行设置和 /koolshare/configs/lucky 配置数据
   - change     管理页面和图标使用独立 Module_lucky_melin.asp / icon-lucky_melin.png，避免与官方 Lucky 页面资源冲突

1.6.2
   - fix        修复管理操作锁文件删除竞态，避免极端情况下两个启动/停止操作并发执行
   - fix        守护进程使用Lucky绝对路径，移除无效base.sh子进程调用，降低异常环境下反复拉起风险
   - fix        Lucky启动失败时向上返回失败状态，避免上层误判为启动成功
   - fix        启动检测增加1秒PID稳定性确认，识别perp快速崩溃/重启循环并主动停止守护
   - fix        安装包显式保留install/uninstall/config脚本及Lucky核心执行权限，避免部分KoolCenter离线安装失败
   - fix        卸载时清理锁文件和PID残留
   - fix        安装时从实际Lucky二进制读取内核版本，移除过期的2.10.9硬编码状态
   - optimize   插件页面隐藏时暂停状态轮询，启用状态轮询由10秒调整为15秒，降低路由器后台Shell/API调用频率
   - fix        查看插件日志改为单次读取，不再因缺少结束标记每500ms重复轮询

1.6.1
   - fix        移除NAT/防火墙重载时无条件重启Lucky的N110钩子，避免长期反复重启造成网络资源和内存/Slab持续增长
   - fix        修复Lucky异常退出后perp守护目录未清理，避免残留守护状态导致重复拉起
   - fix        修复守护模式启动失败后仍由perp无限重复拉起的问题，启动检测失败会主动撤销守护
   - fix        修复非守护模式PID文件清理路径不一致，并优先正常终止进程后再强制结束
   - fix        修复未选择任何重置项时仍会执行普通Lucky启动命令的问题，避免产生重复实例/端口冲突
